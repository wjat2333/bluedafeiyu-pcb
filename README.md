# DeepSeek 蓝色大肥鱼 · NFC 彩色丝印 PCB

> 🐋 以「蓝色大肥鱼」为主题的彩色丝印 PCB 卡片：双面彩印 + 沉金描边，可选 NFC 触碰交互；圆角卡片带挂孔，可作挂件、收藏摆件或桌面装饰。

## 📖 项目简介

本项目使用 **嘉立创EDA 专业版** 绘制，是一块以 DeepSeek 社区人气角色「蓝色大肥鱼」为原型的艺术 PCB 卡片。

板子本身没有复杂的电路，重点是把 PCB 当成画布：用**双面彩色丝印**还原插画，用**沉金**做金色描边、花边与文字，让成品介于「卡片」和「金属徽章」之间。

源工程内包含两个 PCB 版本，按需选择下单：

- **有 NFC 版本**：板载 NT3H2111W0FHKH NFC 芯片与板载线圈，手机触碰即可读写 NDEF 内容（网址、文本、APP 等），并预留 0603 红色 LED 与 0402 10Ω 电阻。
- **无 NFC 版本**：纯装饰板，背面无器件，适合只要画面、不需要交互的场景。

> 角色为爱好者同人创作，与 DeepSeek 官方无关。

## ✨ 设计亮点

1. **双面不同构图**
   - 正面：闭眼微笑的蓝发少女怀抱蓝色鲸鱼玩偶，背景是贝壳、星星、爱心气泡与金色描边的水下场景；
   - 背面：睁眼 Wink 的少女，配「NFC」字样、猫爪、蝴蝶结与花边，NFC 版本顶部是芯片与线圈区域。
2. **彩色丝印 + 沉金分层**
   - 彩色丝印负责插画主体与渐变；
   - 沉金负责轮廓线、花边、星星与文字，形成金属光泽与彩印的层次对比。
3. **圆角卡片 + 挂孔**
   - 66.7 × 100 mm 左右的竖向卡片，R4 圆角；
   - 右上角 Ø4.318 mm 通孔，可直接穿挂绳、钥匙扣。
4. **NFC 线圈画在板内**
   - 无需外接天线，手机靠近背面即可读取；
   - 线圈参数可用嘉立创EDA 的「NFC 工具箱」重新计算。
5. **完整开源工程**
   - 原理图、PCB、丝印图、Gerber 全部开放，可自行改图、改色、改文字后重新打样。

## 📡 NFC 功能与硬件

NFC 部分基于 **NT3H2111W0FHKH**（NXP NTAG I2C plus 系列，13.56 MHz，XQFN-8 封装）。手机靠近板载线圈即可读取芯片内的 NDEF 数据。

| 位号 | 器件 | 封装 | 立创商城编号 | 说明 |
|---|---|---|---|---|
| U1 | NT3H2111W0FHKH | XQFN-8（1.6 × 1.6 mm） | C710403 | NFC 标签芯片 |
| R1 | 10Ω ±1% | 0402 | C2906862 | 串联电阻，可换 0805 / 1206 便于手工焊接 |
| LED1 | 红色贴片 LED | 0603 | C965799 | 焊接时注意正负极方向 |

**写入内容：**

1. 手机安装 NFC Tools / NFC Tools PRO；
2. 将手机靠近板子背面的线圈区域；
3. 写入网址、文本或 APP 启动指令，即可触碰触发。

> 线圈的匝数、线宽、电感值如需调整，建议使用嘉立创EDA 内置的「NFC 工具箱」重新计算；芯片参数可查阅 [NT3H2111W0FHKH 商品页](https://item.szlcsc.com/749561.html)。
>
> 根据社区经验，串联电阻在 0～100Ω 范围内一般也能正常工作；本项目使用 0402 是为了不遮挡画面，实际可按手头器件替换。

## 🛠️ 使用方式

### 方式 1：导入源工程（推荐，可修改）

1. 打开 **嘉立创EDA 专业版**；
2. `文件 → 导入 → 嘉立创EDA 专业版`，选择 `.epro2` 文件；
3. 在 PCB 列表中选择「有NFC版本」或「无NFC版本」；
4. 核对板框、彩印图、NFC 线圈后提交打样。

### 方式 2：Gerber 直接下单（快速，不可改）

上传对应的 `Gerber_*.zip`，按下方「打样参数」选择工艺。**彩色丝印务必勾选并确认双面。**

### 方式 3：焊接与烧录（仅 NFC 版本）

- 焊接 U1（XQFN-8）、R1（0402）、LED1（0603），注意芯片引脚方向与 LED 极性；
- 0402 电阻手工焊接困难时，可换成 0805 / 1206，不影响功能；
- 用 NFC Tools PRO 写入内容后，手机触碰即可使用。

## ⚠️ 打样参数（建议值）

| 参数 | 建议值 |
|---|---|
| 板材 | FR-4 |
| 层数 | 2 |
| 板厚 | 1.6 mm |
| 外层铜厚 | 1 oz |
| 表面处理 | 沉金（金色） |
| 彩色丝印 | 双面开启 |
| 阻焊 / 字符颜色 | 以工程预览为准，下单前核对 |
| 数量 | 5 片起 |
| 测试 | AOI + 飞针 |

> 1. **彩色丝印是收费工艺**，需在订单中单独勾选，并确认正反面都已开启；
> 2. 有 NFC 版本含 0402 / 0603 器件，建议自备烙铁或热风枪手工焊接；
> 3. 彩色丝印存在轻微色差，属工厂正常现象；
> 4. 板子没有专门的电气测试点，飞针测试主要用于工厂侧数据完整性校验；
> 5. 以上为建议值，实际以下单页参数为准。
